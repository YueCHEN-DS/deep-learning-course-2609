Model 1: Multinomial Logistic Regression

Classical Linear Classification via L-BFGS Convex Optimization

Classical ML • 92.59% Test Accuracy

Mathematical Formulation

The model computes a direct linear dot product between all 784 flattened pixels and 10 class weight vectors, followed by a Softmax normalization:

Component Dimension Parameters
Input Vector ($x$) 1 × 784 0
Weight Matrix ($W$) 10 × 784 7,840
Bias Vector ($b$) 10 10
Total Parameters 7,850 weights ~42 KB Payload

Scikit-Learn Implementation (train_sklearn.py)

from sklearn.linear_model import LogisticRegression clf = LogisticRegression( solver="lbfgs", max_iter=250, C=1.0, random_state=42 ) clf.fit(X_train, y_train) # Trains in 6.26 seconds!
Key Insight for Presentation: Because Logistic Regression has zero hidden layers, its decision boundary is strictly planar. It cannot model complex stroke interactions (e.g. crossing strokes or closed loops), which causes its accuracy to plateau at ~92.6%.

Model 2: PyTorch Multi-Layer Perceptron (MLP)

Deep Non-Linear Feed-Forward Network with ReLU & Dropout Regularization

Deep Learning • 97.68% Test Accuracy

Layer-by-Layer Architectural Architecture

The MLP introduces two hidden dense layers with non-linear activations ($\text{ReLU}(z) = \max(0, z)$) and $20\%$ dropout to learn hierarchical combinations of pixel values:

Layer Operation Output Dim Parameters
Input Flatten 784 0
Hidden 1 (fc1) Linear + ReLU + Dropout(0.2) 256 $784 \times 256 + 256 = \mathbf{200,960}$
Hidden 2 (fc2) Linear + ReLU + Dropout(0.2) 64 $256 \times 64 + 64 = \mathbf{16,448}$
Output (fc3) Linear + Softmax 10 $64 \times 10 + 10 = \mathbf{650}$
Total 3-Layer Deep MLP 218,058 parameters (~880 KB)

PyTorch Module Definition (train_mlp.py)

class DigitMLP(nn.Module): def __init__(self): super().__init__() self.fc1 = nn.Linear(784, 256) self.fc2 = nn.Linear(256, 64) self.fc3 = nn.Linear(64, 10) self.relu = nn.ReLU() self.dropout = nn.Dropout(0.2)
Key Insight for Presentation: By adding two hidden layers with non-linear activation functions, the MLP jumps from 92.59% to 97.68% accuracy (+5.09 percentage points). However, because it is fully connected, the first layer alone requires 200k parameters.
